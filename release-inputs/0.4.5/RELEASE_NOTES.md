Viewer 0.4.5 增加设备日志下载：在“授权、升级与日志”中选择客户设备配置 device.json，点击“导出设备日志”，再点击“打开日志保存位置”。日志保存在运行 Viewer 的电脑，无需操作 RTX 的显示器。

- Ubuntu 提供 AppImage；Windows 提供 x64 安装版和便携版。
- RTX 本机 Viewer 自动使用已安装的客户授权配置。外部电脑使用厂商提供的客户配置及配套证书；这些文件不随公开安装包发布。
- 设备须开机、网络可达并已安装诊断服务；旧 RTX 请先联系厂商补装。只升级 Viewer 不会自动补装主机服务。
- 相机关闭时也可导出；一分钟内重复导出可能返回同一份日志。日志包含指定服务运行记录及数值使用统计，不包含图像、模型或密钥。
- 深度图和点云统一在 Viewer 内选择 2D／3D。RTX 标准安装只保留一个 Viewer 快捷入口，原重复入口备份保留。
- 改进相机断连和开启失败的提示；调参密码继续由设备配置管理。

本次只更新 Viewer，Python/C++ SDK 继续使用 [0.4.4](https://github.com/QianYunWuJie-Tech/Qianyun_Synnover_AI3D_Product/releases/tag/v0.4.4)。既有模型、标定和客户数据不随 Viewer 安装包更换。0.4.4 Release 保留供回退。

验收：Ubuntu 已在 RTX 客户桌面及外部电脑实测日志导出和相机出流；Windows 版在厂商 Ubuntu 电脑使用 MinGW 本地编译，已在 Wine 11 完成从 0.4.4 升级、重装、目录迁移、文件占用拒绝、卸载保留客户文件，以及模拟源 2D／3D、同步保存和认证日志下载测试。此版尚未在原生 Windows 10/11 实机验证 UAC、网络防火墙恢复及真实相机；Wine 结果不作为这些项目的通过证据。
