SYNNOVER AI3D Python SDK 接口参考

适用接口：正式 SDK 0.4.1；Python 3.7 兼容候选的验证状态以主使用说明中的安装表为准。更新：2026-10-13。本文列出函数、参数类型、返回值、异常与可运行测试片段。

1. 使用约定

SDK 是网络客户端。模型推理与相机驱动在 RTX 主机运行；客户端负责数据传输、解码、方向变换和点云整理。客户电脑无需 CUDA、TensorRT 或模型。所有深度和点云测量应先排除非有限值。

后文单函数测试默认已连接相机，并使用同一线程操作对象。会改分辨率、方向或关闭采集的例子应在允许操作设备时单独运行。测试用例描述了预期行为，不代表每种操作系统、相机和业务场景均已完成验收。

from pathlib import Path
import numpy as np
from synnover_ai3d import SYNNOVERCamera
camera = SYNNOVERCamera()
camera.open("192.168.88.2", "640x480")

执行完测试后调用 camera.stop()（C++：camera.stop();），并处理异常。保存测试请每次使用尚不存在的新目录。

2. SYNNOVERCamera

创建对象无网络副作用；open 才连接设备。读取同一时刻的多类数据时，先 get_frame，再调用 FrameSet 方法；连续调用 camera.get_rgb 和 camera.get_depth 会分别取新帧。

2.1 discover

发现同一局域网中的设备

discover(timeout_ms: int=2500, discovery_port: int=47649) -> list[Device]

项目

说明

参数与类型

timeout_ms：扫描时间，1–600000 毫秒；discovery_port：UDP 发现端口，默认 47649。

返回值与类型

设备列表；未发现时为空。网络禁止广播时可在 open 中直接填写 IP。

错误处理

格式/范围错误：Python ValueError，C++ std::invalid_argument；像素越界：Python IndexError，C++ std::out_of_range；网络、状态、文件错误：Python RuntimeError，C++ std::runtime_error。

测试用例（接在本节初始化之后）：

devices = SYNNOVERCamera.discover()
assert isinstance(devices, list)
for d in devices: print(d.id, d.address)

2.2 open

连接设备，开启采集并等待第一组同步结果

open(address: str="", resolution: str="640x480", timeout_ms: int=180000, port: int=47650) -> None

项目

说明

参数与类型

address：推理主机 IP，空字符串为自动发现；resolution：640x480 或 1280x720；timeout_ms：1–600000 毫秒；port：控制端口，1024–65535。

返回值与类型

成功无返回值。模型初始化或网络失败抛出异常。多设备环境应指定 IP。

错误处理

格式/范围错误：Python ValueError，C++ std::invalid_argument；像素越界：Python IndexError，C++ std::out_of_range；网络、状态、文件错误：Python RuntimeError，C++ std::runtime_error。

测试用例（接在本节初始化之后）：

camera.open("192.168.88.2", "640x480")
assert camera.get_status()["connected"]

2.11 set_orientation

设置顺时针方向及持久锁定

set_orientation(clockwise_degrees: int, locked: bool=False, timeout_ms: int=5000) -> None

项目

说明

参数与类型

clockwise_degrees：0、90、180、270；locked：true 保存并锁定，false 临时调整/解锁；timeout_ms：确认超时。已锁定时先用原角度解锁再改。

返回值与类型

格式/范围错误：Python ValueError，C++ std::invalid_argument；像素越界：Python IndexError，C++ std::out_of_range；网络、状态、文件错误：Python RuntimeError，C++ std::runtime_error。

测试用例（接在本节初始化之后）：

s = camera.get_status()["orientation"]
camera.set_orientation(s["degrees"], False)
camera.set_orientation(90, True)
assert camera.get_status()["orientation"]["degrees"] == 90

3.7 尺寸、标识与元数据

字段/函数

类型

含义

width / width()、height / height()

int

3.8 pointcloud 与 PointCloud.export_ply

pointcloud(stride: int=1, near_m: float=0, far_m: float=100) -> PointCloud
PointCloud.export_ply(path: str) -> None

stride 为 1–64；near_m/far_m 为有限米制距离，0 ≤ near_m < far_m。返回范围内有效点；Python 的 cloud.xyz 是 (N,3) float32、cloud.rgb 是 (N,3) uint8；C++ cloud.points 为 std::vector<Point>，每点含 float x/y/z 和 uint8_t r/g/b。导出路径必须尚不存在。

cloud = frame.pointcloud(stride=2, near_m=0.1, far_m=5.0)
assert cloud.xyz.shape == cloud.rgb.shape
cloud.export_ply("cloud-api-001.ply")

5. Context 与返回结构

Context.discover(timeout_ms=2500, discovery_port=47649) 与 SYNNOVERCamera.discover 等价。Python 返回 list[Device]，C++ 返回 std::vector<Device>。Device.id/name/address 为字符串、port 为整数、simulated 为布尔值；simulated=true 表示模拟设备。

from synnover_ai3d import Context
for device in Context().discover():
    print(device.id, device.address, device.simulated)

6. 方向、保存与失败处理

连接时自动读取设备已保存方向；无需访问设备文件。使用 frame 的 intrinsics 处理对应图像，不要重复旋转。相机图像控制（曝光、亮度等）由设备管理服务加载已保存默认值，当前 SDK 未公开这些参数的直接编辑接口，需使用授权调参工具。Viewer 的点大小、显示距离和视角是客户端显示设置，不会自动传给 SDK。

停止后 get_status 只保证最小状态字段；读取 orientation 前先确认字段存在。多线程应用请串行访问同一相机对象。断线或超时捕获异常后先读取状态，不把空数组当作成功结果；关闭失败需要重试或人工确认。
